Quick help

Node: choose Node mode, then click the canvas. In Node mode you can also drag existing nodes to reposition them (Blender-style).

Edge: choose Edge mode, then drag from a source node to a target node. On touch screens, tap a source node, then tap a target node.

Move nodes: choose Select or Node mode and drag nodes.

Transform gizmo: with nodes selected in Select mode, use the gizmo row (keys 1–4) to translate, rotate, scale or rect-stretch the positions of the selected nodes — node sizes and styles never change. Drag the pivot dot in Rotate/Scale to move the rotation centre (double-click resets it). Shift snaps rotation to 15° and locks scale/rect proportions; Alt stretches the rect from its centre; Esc cancels a gizmo drag. Arrow keys nudge the selection (Shift = bigger step; grid step when snap is on). Key G shows/hides the gizmo.

Move canvas: choose Move mode, hold Space, or drag with RMB/MMB in any mode. On touch screens, pinch to zoom and pan.

Center on edge: in Move mode, click an edge — the view centers on whichever endpoint is further from the current view center.

Adjust numbers: hover any numeric field with a ⇆ handle and drag horizontally to change the value (Shift = fine). Type directly to enter an exact value.

Matrix editing: click a cell once to select it without triggering the keyboard; click again to edit it. This lets you select on mobile without the on-screen keyboard popping up.

Zoom: mouse wheel / trackpad over the canvas, or pinch on mobile/tablet. Camera position can also be set numerically in the Data tab.

Exports: every format (JSON, DOT, GraphML, Edges/Matrix/Nodes CSV) supports both file download and copy-to-clipboard.

Copy / paste selection: Ctrl+C copies the selected nodes with the edges between them, Ctrl+X cuts, Ctrl+D duplicates in place, Ctrl+V pastes with an offset (also across tabs, via the system clipboard). Edges with only one endpoint in the selection are restored on paste when the other endpoint still exists — see "Preserve dangling edges" in the Edit tab.
